- Добавлена генерация конфигураций Cloudflare WARP для WireGuard и AmneziaWG с сохранением, обновлением и отзывом регистрации устройства.
- В разделе «Маршрутизация → Cloudflare WARP» можно включить WARP как выход через выбранный VPN. Сайты, направленные по этой цепочке, получают выход через WARP. Основной VPN должен поддерживать UDP; прямые маршруты и правила с другим явно выбранным профилем сохраняют свой путь.
- Созданную конфигурацию можно добавить в обычные профили для отдельного подключения к WARP.
- Исправлена подготовка версий APK и описаний выпусков: версия берётся из тега, а ручная проверочная сборка может сохранять APK без публикации релиза.
- Обновлена встроенная база GeoSite: прежний закреплённый файл больше не доступен у поставщика и мешал сборке.
